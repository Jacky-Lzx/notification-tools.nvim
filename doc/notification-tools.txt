*notification-tools.txt*  Notifications and progress for Neovim 0.10+

SETUP                                                  *notification-tools*
>
    require("notification-tools").setup({})
<
No dependencies. Ordinary notifications appear at the top right. Progress tasks
appear at the bottom right. Requiring the module alone has no setup side effects.
The first API call initializes defaults if setup has not been called.

API                                            *notification-tools-api*
>
    local tools = require("notification-tools")
    local id = tools.notify("Hello", "info", { title = "Build", timeout = 4000 })
    tools.notify("Updated", "warn", { id = id })
    tools.dismiss(id)
<
notify(message, level?, opts?) returns an ID, or nil when filtered. Levels may
be vim.log.levels values or case-insensitive names. opts: id, replace, title,
icon, source, details, markdown, timeout. details is optional secondary text. timeout=0 pins a
notification. IDs are strings or finite numbers.
Replacements update the corresponding history entry. Timeouts start at creation.

Body and details support inline Markdown by default: **bold** / __bold__,
*italic* / _italic_, backtick code spans, ~~strike~~ and [label](url). Links show
their label; the complete URL stays in history. Escapes and literal code content
are preserved. Supported spans stay styled across automatic window wrapping.
Markup spans are limited to one logical line. Block layouts/HTML are not rendered;
fenced code blocks stay literal. This is not a full Markdown document renderer.
Titles/tasks remain plain text, and history keeps the original Markdown source.
The history window highlights time, level, title, body and Markdown spans.
Markdown delimiters/URLs are concealed without changing buffer text.
Yanks copy original Markdown. Conceal settings are local
to this history window. A notice with markdown=false stays literal.
In Normal mode the cursor line reveals its Markdown source; other lines stay
concealed. Moving the cursor conceals the previous line and reveals the new one.
Set notification.markdown=false globally, or pass opts.markdown=false for a raw
message. Per-notice mode is inherited on explicit updates. Different modes never
auto-merge, even with identical source text.

Without an explicit id/replace, identical active notices merge: title, body,
details, severity, icon and timeout must match. The same ID is returned, count
increases, and the timeout restarts. Explicit updates preserve count unless the
content changes. Explicit IDs stay independent. Set notification.merge_duplicates
to false to disable automatic merging. History includes the merged count.

history() returns an independent oldest-first snapshot of notification records.
show_history(opts?) opens a scrollable history window, newest created/updated
records first. The history() API remains oldest-first. clear_history() clears history.
history(opts?) also accepts filters: level (minimum), source (exact match), title
(case-insensitive literal substring). Conditions intersect; source defaults to
the original notice title. These filters do not change the stored records.
:Notifications [level=warn] [source=lua_ls] [title=Build] accepts the same filters.
Use the Lua API for source/title values containing spaces.
History keys: ]n/[n next/previous notice; gl minimum level; gs source; gt title;
r refresh; R reset filters and refresh; q/Escape close. Prompts use vim.ui.
Refresh retains the window/buffer and anchors the cursor to the selected notice
ID and line offset when it is still available. New notices do not auto-refresh.
Active filters and the visible record count appear in the window title.
dismiss() closes all ordinary notifications, preserving history and tasks.

READING                                        *notification-tools-reading*

show_notification(id?) opens one complete notice. Without an ID, it chooses the
most recently created/updated ordinary notice. Explicit IDs can also address task
result history. Returns the record ID, or nil if unavailable. Window work is
scheduled. :NotificationsLatest reads the latest ordinary notice. In history,
<CR> reads the selected record. q/Escape close; r refreshes its current content.

Reading an active notice pauses its remaining timeout. Closing resumes the
remaining time, rather than a fresh full timeout. Replacing/merging a notice while
reading resets that remaining time to the new timeout; r shows the updated text.
Pinned notices remain pinned. Expired/dismissed notices are read from history and
are never resurrected. history_size=0 still permits reading a live notice.
Only one history/reading window is open at a time. Switching readers, externally
closing/wiping the buffer, setup and teardown clean up the reading state. Reading
windows appear above the plugin's ordinary popups and task panel. They use the
same filetype, colors and cursor-line source reveal as history.

ROUTING                                        *notification-tools-routing*

notification.dnd=false enables do-not-disturb when true. Only levels at least
notification.dnd_level (ERROR by default) pop up; OFF suppresses all levels.
Tasks are unaffected. Suppressed notices stay in history and are never replayed.
set_dnd(boolean), toggle_dnd(), is_dnd() return the resulting/current state.
:NotificationsDnd [on|off|toggle] toggles when no argument is given.

notification.filter is an optional synchronous callback receiving independent
normalized fields (message, level, title, source, details, timeout, etc.). Return
"show" or nil for normal display, "history" for history only, "drop" to ignore
(returning nil from notify). DND also applies to "show". The global minimum level
is checked first. Errors/invalid results are reported without recursive notify,
and fall back to "show". source defaults to title and is inherited on replacement.
Different sources do not auto-merge.

PROGRESS                                       *notification-tools-progress*
>
    local task = tools.progress({
      id = "producer:job:1", title = "Build", source = "my-plugin",
      message = "Starting", percentage = 0,
    })
    task:update({ percentage = 60, message = "Compiling" })
    task:finish("Ready")
<
The caller owns its events, handles, and actual work cancellation. The plugin
does not listen to business-plugin events. Use namespaced IDs to avoid clashes.

progress(opts) returns a handle with id and the following methods:
  :update(opts)             Update title/source/message/percentage/history.
  :finish(message?, status?) End with success (default), error or cancelled.
  :cancel(message?)        Mark cancelled; does not cancel the producer's work.
  :is_active()             Whether updates are still accepted.

percentage is clamped to integer 0..100. Omitted fields retain their values.
The same active ID returns the same handle. Ended IDs may be reused. Old handles
are inert after completion, eviction, clear_tasks(), setup(), or teardown().
Mutation methods return the handle. After setup on the main loop, notification
and task methods are safe from libuv callbacks. Window changes are scheduled
onto the main loop and do not take focus.

tasks() returns newest-first task snapshots. clear_tasks() clears all tasks.
Completed results remain for progress.done_ttl milliseconds. Silent tasks time
out after progress.stale_timeout milliseconds; 0 disables this timeout.

TASK RESULTS                                   *notification-tools-task-history*

progress.history="errors" (default) records failures and inactivity timeouts in
notification history. false disables recording; "all" also records success and
cancellation. progress({ history = ... }) or handle:update({ history = ... })
overrides the policy for one task. Clearing/evicting tasks does not record them.

Results include title/source, final message, status and duration (milliseconds).
Each run gets an independent history ID; task_id preserves the producer ID.
Task records have kind="task"; ordinary notices have kind="notification".
Success uses INFO, errors ERROR, cancellations WARN. Task content is plain text.
Results remain after done_ttl; they share history_size with ordinary notices.
history_size=0 disables all recording. Results never create extra popups and
use the task recording policy, bypassing ordinary filters/minimum level/DND.

OPTIONS                                        *notification-tools-options*

notify=true              Own vim.notify; false only enables the explicit API.
level=INFO               Minimum notification severity.
timeout=4000             Notification lifetime in milliseconds; 0 pins.
history_size=200         Maximum notification records; 0 disables history.
max_notifications=5     Maximum visible notification windows.
max_pending=100          Maximum records each for notifications and tasks.
window.border="rounded" rounded/single/double/solid/none or empty string.
window.winblend=0        Window transparency (0..100).
window.min_width=24      Preferred minimum notification width, in cells.
window.max_width=60      Maximum window width, constrained by the screen.
window.max_height=8      Maximum notification body lines.
window.top/right/bottom=1 Screen margins in cells.
window.zindex=150        Float stacking priority.
window.gap=1             Space between notices / between the two areas.
notification.merge_duplicates=true  Merge identical active notices.
notification.markdown=true          Render inline Markdown in body/details.
notification.timestamp=true         Time in the header; replaced by repeat count.
notification.fade_out=180            Fade during the final timeout milliseconds.
notification.window      Inherits window, with horizontal padding=2, vertical=0.
progress.window          Inherits window (rounded border), with min_width=24,
                        max_width=44, max_height=12 and horizontal padding=1,
                        vertical=0. max_height includes headers and details.
*.window.padding         { horizontal = cells, vertical = lines }.
progress.enabled=true   Show the task panel; API remains available when false.
progress.max_items=6     Maximum visible task entries, excluding source labels.
progress.done_ttl=1500   Result lifetime in milliseconds.
progress.history="errors" Failure/timeout history; "all" or false also supported.
progress.group_by_source=true       One source label per task group.
progress.show_elapsed=true          Elapsed time when percentage is absent.
progress.fade_out=240               Fade finished tasks during the final done_ttl
                                   milliseconds, leaving active siblings intact.
progress.stale_timeout=120000 Time without updates before timeout; 0 disables.
progress.interval=80    Refresh interval in milliseconds (minimum 16).
progress.avoid          Current-window filetypes that hide progress.
progress.spinner        Nonempty list of nonempty animation frame strings.
lsp.enabled=true        Subscribe to LspProgress/LspDetach without replacing
                        server handlers or consuming the progress queue.
lsp.ignore={}           Ignored LSP client names.
icons                   TRACE/DEBUG/INFO/WARN/ERROR icon strings.

window remains a shared fallback. notification.window and progress.window can
override it independently. A notice's max_height limits body/details lines.
Task source labels, gaps and detail lines are omitted first on small screens.
Widths are measured from content and only grow during a float's lifetime, except
when the screen shrinks. Source groups and their tasks keep creation order.
Notices append in creation order; updates do not reorder them. Recent notices
are preferred on overflow. Public task/history snapshot ordering is unchanged.

Fade durations of 0 disable fading. Fades do not extend timeout or done_ttl;
pinned notices never fade. True-color terminals provide the best color blending.
Lists replace defaults. Screen space is shared without overlap between the two
areas. Hidden notifications still expire; full messages remain in history.
Repeated setup clears state. teardown() removes owned resources and restores
the prior vim.notify only when this plugin still owns the function.

COMMANDS                                       *notification-tools-commands*

:Notifications           Show colored history with Markdown conceal and cursor-line
                         source reveal; q or Escape closes it.
:NotificationsDismiss    Dismiss ordinary notifications.
:NotificationsClear      Clear notification history.
:NotificationsDnd [on|off|toggle] Toggle do-not-disturb (no argument also toggles).
:NotificationsLatest     Read the latest ordinary notice; pause its active timeout.
:NotificationToolsDemo   Show example notifications and a progressing task.
:checkhealth notification-tools
